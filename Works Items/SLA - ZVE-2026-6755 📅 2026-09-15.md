triggering link 

1. Identify a valid Arattai contact row  
    For example, during testing the following valid Contacts data row was used: 22538
2. Trigger an audio call, Arattai processes the external intent and enters the outgoing audio-call flow for the specified Arattai contact.  
    adb shell am start -W -n com.aratai.chat/com.zoho.chat.MessageAction -a android.intent.action.VIEW -d "content://com.android.contacts/data/22538" -t "vnd.android.cursor.item/vnd.com.aratai.chat.call.audio"
3. Trigger video call, The same issue can be triggered for video calls:  
    adb shell am start -W -n com.aratai.chat/com.zoho.chat.MessageAction -a android.intent.action.VIEW -d "content://com.android.contacts/data/22538" -t "vnd.android.cursor.item/vnd.com.aratai.chat.call.video"
